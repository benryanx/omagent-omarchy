# Security

Never post credentials, browser cookies, pairing links or exploit details in a
public issue. Use the repository's private vulnerability reporting facility:

https://github.com/benryanx/omagent-omarchy/security/advisories/new

This is an experimental Linux preview. Keep credentials in your local app's
credential settings or explicitly configured environment. User profiles,
Telegram bindings, saved browser sessions and Agentcard credentials are not
release assets. Hosted subscriptions and automatic updates are disabled.

If a credential has been exposed, revoke or rotate it with its provider;
removing a file from a later release does not revoke it.
